# v8.3.2 每轮任务框滚动补丁

适用于已安装 v8.3.2（可包含 UTF-8 修复）的项目。本补丁仅更新 web/index.html，不修改研究工作进程、配置或输出。

## 安装

把本包的 web 文件夹解压到项目根目录，覆盖 web/index.html；浏览器按 Ctrl+F5 强制刷新。

如果只是应用这份网页补丁，可以让当前研究继续，不需要重启研究进程。完整合并升级包涉及后端文件，仍应等待本轮结束、关闭服务器后覆盖。

## 行为

“每轮成果”中本轮任务的绿色文本框最大高度为240px，长内容在框内纵向滚动，短内容自然显示。内容完整保留，可以选中复制；文本框可用Tab聚焦并通过键盘滚动。刷新同一轮成果保留滚动位置和焦点，切换轮次从顶部显示。

如需调整高度，可在 web/index.html 中搜索 #roundResults .round-goal，把 max-height:240px 修改为所需高度。

## 验证

实际前端JavaScript通过语法检查及DOM检查：最大高度、滚动样式、完整长文本、键盘焦点、同轮刷新保留位置、新轮位置重置。后端沿用此前已通过58项自动测试的 v8.3.2 + UTF-8 合并版本。本次没有新建或重复运行后端测试。
