# PhysMaster v9.4 网页补丁 1

这个补丁适用于已经安装 v9.4 的项目，只需替换 `web/index.html`。
它不会修改 Python 后端、模型配置、历史输出、科学评分或签收规则。

## 安装

1. 解压补丁 ZIP。
2. 打开你正在运行的 PhysMaster 项目，进入 `web` 文件夹。
3. 把原来的 `index.html` 复制备份，例如命名为 `index-before-webfix.html`。
4. 将补丁中的 `web/index.html` 复制进去，替换原文件。
5. 回到网页，按 **Ctrl + F5** 强制刷新。

只替换上述一个文件；README、tests 和 validation 不需要复制到项目中。
当前服务器每次打开首页都会读取这个 HTML 文件，因此无需为了安装网页补丁停止正在运行的研究。
安装后页面右上角应显示“本地运行 · 网页修复 1”。
如果出现问题，将备份恢复为 `web/index.html`，再按 Ctrl + F5 即可回退。
此页面使用 v9.4 的继承接口；不要直接覆盖尚未升级到 v9.4 的旧版本。

## 修改内容

### 网页请求失败与恢复

- 单独显示网页连接状态，并标注失败接口。
- GET 读取请求超时为 12 秒；网络失败、超时或 HTTP 5xx 最多自动重试一次。
- 连续刷新失败后按 2、4、8、15 秒间隔重试；恢复后清除连接失败提示并显示“连接已恢复”。
- 请求失败时保留已经显示的研究记录。
- POST 发送请求超时为 60 秒，不自动重发。未收到可靠回复时提示操作结果尚未确认，并保留输入的条件。
- 初次读取设置失败时允许自动恢复，无需刷新整页重新初始化。
- 自动读取继承文件清单的间隔调整为至少 5 秒，减少反复扫描；用户搜索和翻页仍会立即读取。
- 防止切换任务后，旧任务迟到的状态请求覆盖新任务页面。
- 连接恢复不会清除独立的提交错误，避免把未确认的发送操作显示成成功。

### 科学分与验收解释

- 折叠卡片显示科学分、本节点评审时记录的通过阈值、是否达标及未通过原因。
- 即使 Critic 建议和最终决定一致，也会显示“Critic 仍建议修订”等原因。
- 展开卡片后新增“验收依据”，列出原始建议、最终决定、关键问题、程序核对和规则记录。
- 使用节点自身记录的阈值；历史节点没有阈值记录时明确说明，不用当前设置猜测。
- 比较和提示使用原始科学分，例如 0.7499 不会因为其他位置显示为 0.75 就被描述为达标。
- 大字 reward 仍为综合排序分；程序原有验收决定保持不变。

例如科学分 0.78、阈值 0.75、Critic 建议修订的节点，会显示：

> 科学分 0.78 · 本节点通过阈值 0.75（科学分已达标）。尚未验收：Critic 仍建议修订。

如果旧节点没有记录具体原因，页面会明确说明缺少记录，不会编造解释。

## 验证范围

6 个基于实际 HTML 页面的自动测试脚本，共 37 组检查通过。
覆盖故障恢复、超时、GET 重试、POST 不重试、原始阈值、阻挡原因、历史轮次导航、展开状态、继承页面和转义显示。
本次没有修改后端，也没有调用真实 DeepSeek API。测试使用模拟 HTTP 响应和 jsdom，未在你的 Windows 电脑上复现最初的连接故障。

完整测试记录位于 `validation/ui-tests.txt`，测试源码位于 `tests`。
这些测试在安装了 jsdom 的 Node.js 环境中运行；正常安装网页补丁不需要这些测试依赖。

本补丁改善短暂请求失败的处理与显示，不能单靠网页修复后端异常、服务器不可达等故障。如果恢复提示持续不出现，可按状态栏中显示的接口定位服务器错误。
