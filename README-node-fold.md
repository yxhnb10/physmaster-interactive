# PhysMaster v8.3.2：节点折叠与决定调整原因

本补丁在节点成果卡片上新增两项界面功能，直接读取既有评分、规则与审计记录，不修改评分/决策，不增加模型调用。

## 默认折叠，点击查看细则

每个节点默认只显示头部：节点编号、子任务/父节点、当前状态、reward 数值、评分条和评分有效性。点击整个头部（也可键盘 Enter/Space）展开，展示成果、Critic 意见、提炼知识、证据与工具；再次点击收起。完整 JSON 仍放在第二层折叠区。

刷新不会强制收起已展开的节点，已有的原始记录展开状态、内容滚动和焦点继续保留。新一轮或新任务的节点默认折叠。

## 决定调整原因

当保存的 model_decision 与最终 decision 不同时，头部显示「决定已调整」，展开后首先显示「决定调整原因」。标签改为「Critic 原始建议」「规则处理后决定」。

- 有效评分低于节点记录的重做阈值：显示实际分数和实际阈值。
- 通过建议未达到记录的通过阈值：解释为什么不能完成。
- 程序审计 violation 导致重做：显示具体参数/文件等核对问题。
- 程序证据 unchecked 阻止验收：显示缺失证据。
- 保留 policy_reason 中实际记录的评审规则。
- 记录没有明确原因时，显示「没有提供明确的决定调整原因」，不套用默认阈值猜测。缺少 Critic 原始建议的历史记录显示「未记录」，不会把最终决定冒充原始建议。

例如，评分 0.78、重做阈值 0.60，但文件核对 violation，界面会解释文件核对问题，不会误写成低于评分阈值。这里展示的是程序记录与其明确规则，不是新的科学评审。

## 安装

已有 v8.3.2 项目使用 `PhysMaster-v8.3.2-node-fold-patch.zip`：只需将包内 `web/index.html` 覆盖到项目同名位置，然后网页 Ctrl+F5。它包含前一版节点卡片功能，可以直接替换尚未安装卡片补丁的 v8.3.2 页面。当前服务器逐次读取 HTML，无需停止正在运行的任务或重启服务器。

例如覆盖到：`C:\Users\yanxiaohai\Desktop\PhysMaster-v8\web\index.html`。

`PhysMaster-v8.3.2-node-fold-upgrade.zip` 是合并升级包，包含此前 v8.3.2、UTF-8、滚动任务框、Critic 决定保护、最终回答交付和节点卡片功能。该包也覆盖后端文件，需等研究结束/停止任务，再停止服务器后合并覆盖并重启；不含 config.yaml、API 密钥、outputs 和资源数据。

另附 `PhysMaster-node-fold-preview.html`：下载后用浏览器打开，可直接点击模拟节点体验展开和收起，不依赖服务器。所有示例节点与评分均为模拟数据；不要用预览文件替换正式页面。
