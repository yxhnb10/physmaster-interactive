# PhysMaster v8.3.2：每轮节点成果卡片

本次将原先需要展开大段 JSON/日志的「每轮成果」，改为结构化节点卡片。基于已有 research_monitor 数据直接展示，不新增模型调用，不改 reward、Critic 阈值、节点调度或物理计算。

## 展示内容

- 本轮概览：节点数、本节点已验收数、有效评分数、未评分/异常数，以及有效评分均值。未标记评分有效性的旧记录不参与均值。
- 节点卡片：节点编号、父节点、子任务、初稿/修订类型、当前状态、reward 数值与评分条。
- 四个分区：「做了什么」「Critic 怎么看」「学到了什么」「证据与工具」。做了什么优先展示 core_results，其次 numerical_results/analysis；这些是节点报告，不是程序新推断的科学结论。知识直接使用现有 Promoter 输出，不新增总结调用。
- 真正的 0 分保留 0.00；无效评分、执行失败或尚未评审显示「未评分」。缺少 score_valid 的旧评分明确标记为历史评分，不能据此认定验收。
- 「本节点已验收」要求 complete、accept、有效评分与程序审计 pass 同时满足；节点验收不等于整个研究任务完成。未验收节点的知识明确标为下轮修订参考。
- 已知交付失败、程序阻止验收、关键评审问题分别展示。节点目录文件可以下载，但目录中有文件不意味着已验收。
- 完整目标、原始输出、Critic JSON 与工具参数保留在每张卡片底部的折叠详情中；全局运行日志默认折叠。长内容可在各分区内滚动。
- 保留原来的轮次选择、跟随最新一轮和可滚动任务框。刷新保留展开状态、滚动位置和焦点；旧任务迟到的轮次响应不会覆盖新选任务。

## 安装

已经使用 v8.3.2 的用户，推荐 `PhysMaster-v8.3.2-node-dashboard-patch.zip`：

1. 将压缩包里的 `web/index.html` 覆盖到项目的同名路径。例如 `C:\Users\yanxiaohai\Desktop\PhysMaster-v8\web\index.html`。
2. 网页按 Ctrl+F5 强制刷新。当前服务器逐次读取 HTML，因此本界面补丁无需停止正在研究的任务或重启服务器。
3. README、LICENSE 与测试文件用于说明和开发验证，可一起合并。不要把预览 HTML 替换正式的 web/index.html。

如果还没安装之前的修复，可使用 `PhysMaster-v8.3.2-node-dashboard-upgrade.zip`。它包含 v8.3.2、UTF-8、滚动任务框、Critic 决定保护、最终回答交付修复及本次卡片界面。合并升级包修改后端：先等待任务结束/停止任务，再停止服务器，合并覆盖并重启。不含 config.yaml、密钥、outputs 或资源数据。

另附 `PhysMaster-node-dashboard-preview.html`，下载后在浏览器打开即可查看。它使用明确标注的模拟节点，不是实际研究成果，不执行模型/API 请求；文件链接仅为演示。
