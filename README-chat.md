# PhysMaster 本地聊天工作台（联网加速版）

基于你上传的联网加速版及上一版追加条件补丁制作。这是合并覆盖补丁，不是独立完整项目。

## 安装

1. 备份原项目。
2. 把本包中的文件合并到原项目中同时有 run.py 和 config.yaml 的目录：同名文件覆盖，其他原文件保留。
3. 新增 web_server.py 和 web/index.html；run.py、core/supervisor.py、core/theoretician.py、utils/live_updates.py 使用本包版本。send_update.py、tests/ 也可以一起合并。
4. 继续使用原来的 Python 环境和原 config.yaml。网页服务器使用 Python 标准库和原项目已有的 PyYAML，不需安装 FastAPI、Node.js 或前端构建工具。

本包不包含配置文件、密钥、原联网工具和历史结果。不要删除原 core/、utils/、tools/ 目录中未被覆盖的文件。

## 启动

在项目根目录打开终端：

```bash
python web_server.py --cfg_file config.yaml
```

浏览器打开：

http://127.0.0.1:8765

端口被占用可改：

```bash
python web_server.py --cfg_file config.yaml --port 8766
```

网页启动的任务会自动启用 live_updates，无需额外改 config.yaml。若继续用 python run.py 从终端启动，则仍需在现有 pipeline 下配置 live_updates_enabled: true。

## 使用流程

1. 在“开始研究”输入初始问题，点击“开始研究”。不用再改 query.txt。
2. 右侧显示任务状态、完成轮数、条件版本、运行日志。初始条件版本为 0。
3. 在“条件对话”输入追加或纠正条件，点击“发送条件”。
4. 消息状态依次可能为“等待研究进程就绪”“已排队”“已生效 · 条件版本 N”。只有“已生效”表示程序已把该条件纳入新契约，不表示物理约束已被数值结果验证。
5. 若想把多条条件一次应用：点击“本轮结束后暂停”，等待“已暂停”；发送多条条件；点击“继续计算”。条件在继续后合并，重新规划并分配一版新的计算预算。
6. 完成后“研究结果”显示 summary.md 原文。代码、图件和完整结果可从界面提示的输出目录打开。

例：初始任务写“总质量190 kg，静止释放，建立竖直下降模型”。运行时补充“迎风面积取0.7 m²”“追加气动加热估算”。如果需要同时应用两条，先暂停。

## 边界

- 第一版把每条聊天输入都当成补充条件。尚未实现独立的“询问/解释结果”模式，问句也可能触发重新规划。
- 暂停发生在轮间，不中断已发出的模型请求、检索、评审或 Python 计算。初始化或重新规划期间点击暂停，也要等到下一轮边界。
- 修改条件会新建搜索树，旧评分和完成标记不复用；旧契约与轨迹归档，输出文件保留。新条件版本会重新分配轮数和检索预算，可能增加费用。
- 最后一轮之后仍可暂停并添加条件；一旦进入“生成总结”阶段，停止接收条件。
- 未生效的消息会显示“未生效”，不会冒充成功。特别是结束边界、进程异常时，以回执为准。
- 暂时只允许一个网页任务运行，避免共享先验索引争用。完成后可创建新任务，并从下拉框查看本次服务器会话中的任务。
- 页面每秒轮询状态，不使用 SSE/WebSocket；研究工作在独立进程中运行，不阻塞网页请求。
- 刷新/关闭网页不会停止任务，早期排队消息由后端持续投递。网页重新打开后可查看本次服务中的任务。
- 服务器重启后不恢复任务列表/研究进程；输出文件仍保留。请先完成任务再关闭服务器。Ctrl+C 会停止服务，解除暂停，等待已经运行的工作进程完成；不要强行关闭终端。
- 服务仅监听 127.0.0.1，不对外部署；已加入 Host、Origin 和写请求令牌检查。不要改为公网监听使用。

## 输出

网页任务输出位于：

```text
outputs/web/<任务编号>/query/
```

上一级保存初始问题、运行日志和本次任务配置。web_config.yaml 复制原配置，可能包含 API 密钥，请勿分享或上传此运行目录。

## 验证与限制

```bash
python -m unittest discover -s tests -p "test_*.py" -v
```

本次完成 7 项自动测试：原有条件队列及重规划测试 4 项；真实模拟工作进程驱动的网页后端测试 3 项，覆盖初始化排队、暂停批量更新、继续、回执、总结、接口校验和单任务限制。

另外使用模拟 DOM 执行了实际前端 JavaScript，连接本地后端验证创建、暂停、条件状态、继续和结果展示。修改文件通过 Python 编译检查。

当前环境没有浏览器内核，未完成真实浏览器布局验收；没有调用真实 LLM 或联网检索服务，也没有验证完整科研任务的物理输出。模拟工作进程测试不会调用模型 API 或产生模型费用。
