# PhysMaster v8：联网、动态条件与每轮成果监看

这是完整源码项目，基于你实际上传的联网加速版整合。无需先安装 v3、v4、v5、v6、v7，也无需另外运行 Windows 修复脚本。

## 安装与启动（Windows）

1. 先停止原来的网页服务，保留原项目作备份。
2. 解压本包到桌面，进入直接包含 web_server.py、run.py、config.yaml 的 PhysMaster-v8 目录。
3. 将你原项目的 config.yaml 复制到新目录，覆盖包内的脱敏示例配置。模型/搜索 API 的密钥由你本地保留；本包不带真实密钥。
4. 在原来能运行联网版的 Python 环境中打开 Anaconda Prompt 或 CMD：

```bat
cd /d "C:\Users\yanxiaohai\Desktop\PhysMaster-v8"
python web_server.py --cfg_file config.yaml
```

5. 浏览器打开 http://127.0.0.1:8765 。网页创建任务时会自动打开动态条件功能。

本包依赖说明仍为原 requirements.txt；原环境已经能运行时不必重新安装。首次安装才使用：

```bat
python -m pip install -r requirements.txt
```

如果继续使用自建的先验知识索引，也把对应索引和语料按原配置路径放回；这些大型数据不在上传源码中，也不在本包中。

## 合并的修复

- JSON 原子替换遇到 PermissionError 会短暂重试，兼容 Windows 的读取/安全软件瞬时文件锁。
- 长期无法写 progress.json 时警告并让研究继续，网页进度可能暂时滞后。契约、消息与回执仍严格处理错误。
- 网页端暂时读不到状态文件时保留上次状态，避免一次读取失败弄坏进度页面。
- 旧的 v6 缺文件问题通过完整项目打包规避；添加 utils/tools 的本地包入口，避免被其他同名 Python 包覆盖。

## 每轮成果监看

网页右侧新增“每轮成果”：

- 选择“跟随最新一轮”，或手动查看以前的轮次。
- 每轮开始时显示实际派发目标、条件版本。
- 展开节点可以看到实际求解输出、Critic 的决策/评分/意见、整理后的知识、调用工具和生成文件。
- 节点标识显示父节点，便于区分草稿与修订路径。
- 生成文件可以直接下载，完整目录仍位于界面显示的输出路径。
- 一轮可包含多个并行节点，不等于只有一个模型结果。

这些是研究输出与评审记录，不是模型内部思维过程。Critic reward 是模型评分，不是统计置信度，也不保证物理模型正确。

节点执行期间先显示“求解中”；当前批次工作进程返回后，逐步记录输出和评审。不会流式展示正在进行的模型 token 或 Python 仿真的每个时间步。

监看记录写入任务目录的 research_monitor/round_XXXXXX.json，即使 debug_logging=false 也会记录。条件更新前的轮次保留并标注原版本，不自动认定为新条件下已验证。

## 保留的交互功能

- 网页创建任务，查看日志与最终总结。
- 自然语言追加/纠正条件；显示等待、排队、生效回执。
- 本轮结束后暂停；暂停期间可批量追加条件，继续时重新规划。
- 独立输出目录；一次允许一个网页任务运行。
- 关闭或刷新网页不停止任务；研究结束后重新创建任务。

这版不声称已实现外部对话中列举的 v3—v7 全部实验 Agent。尚未实现：独立问答模式、自动实验规划/扫描闭环、即时取消和跨进程断点恢复。每条输入仍视为补充条件，修改后新建搜索树。

## 停止

服务器终端按一次 Ctrl+C，停止接收请求，解除暂停并等待当前任务完成。不要以关闭浏览器代替停止服务器，不要在任务还运行时直接覆盖源文件。
