# PhysMaster Interactive

**基于 PhysMaster 的非官方交互扩展：通过网页开展物理建模、数值研究、节点评审与增量续研。**

本项目在 PhysMaster 的多 Agent 与 MCTS 研究框架上，加入条件对话、成果核对、续研继承、断点恢复、三人小组账号及研究过程可视化，面向小组内部使用和物理建模研究辅助。

本文对应扩展版本 **v9.6.3**，更新于 **2026-10-06**。扩展版本号独立于上游。功能是否可用取决于实际安装的源码与补丁；仅替换 README 不会升级程序。

当前部署采用 **腾讯云 Ubuntu + systemd + Tailscale Serve 私网 HTTPS**。固定三人使用，由管理员创建账号，不开放注册，不使用公网入口。

## 已部署用户：日常使用

1. 通过管理员提供的 Tailscale 私网 HTTPS 地址打开网页，使用自己的小组账号登录。
2. 在“个人 API 设置”保存自己的 API 地址、密钥、默认模型和角色模型；使用 Tavily 时另存搜索密钥。密钥留空表示保留已有值，删除需明确勾选。
3. 点击“新建独立任务”，填写问题和研究名称，选择工具、Critic 阈值及必要的硬性参数。
4. 打开“运行配置：并行、模型预算与快速探索”，确认本次运行设置后开始研究。
5. 查看节点成果、评审与工具证据；需要修改条件时使用“条件对话”。
6. 任务结束后下载成果，或追加条件开始下一轮增量续研。

关闭浏览器或退出登录不会自动停止后台研究。服务器重启后可重新读取历史；中断研究是否可恢复，取决于已有安全检查点。

### 个人 API 与模型分工

小组网页模式使用发起任务成员的个人 API 配置。默认模型用于未指定角色的请求；角色模型可分别配置 `draft`、`revise`、`critic`、`summarizer` 等实际角色。模型必须支持本项目所用接口和工具调用。

**v9.6.3 的网页翻译固定使用 `deepseek-flash`**，沿用翻译者的个人 API 地址与密钥。研究角色模型保持原设置；个人 API 地址须支持该模型。翻译用于辅助阅读，不改写研究原文、参数、评审或成果文件。

已完成译文及成功翻译的批次可复用缓存；缓存按用户、任务、内容、API 地址和实际模型区分。公式、代码、数值等由既有保护逻辑保留。译文有误时应查看原文。

## 任务控制：选择合适的操作

| 操作 | 生效方式 | 成果与状态 |
| --- | --- | --- |
| 发送条件 | 在轮间检查点处理 | 消息排队后显示生效回执；发送成功不等于立即生效 |
| 本轮结束后暂停 | 等当前轮到达检查点 | 暂停期间可积累条件，再点击继续计算 |
| 继续计算 | 解除轮间暂停 | 继续当前任务，处理已排队条件 |
| 强制停止研究 | 核对并终止目标研究及计算进程 | 保留已落盘文件；未完成调用、计算和未保存进度可能丢失 |
| 恢复中断研究 | 回到原任务安全检查点 | 使用原任务目录和保存的配置，重做被中断的工作 |
| 基于旧成果继续研究 | 新建增量任务 | 使用新的进程与输出目录，保留旧任务和继承快照 |
| 取消排队 | 取消尚未启动的任务 | 不启动研究或调用模型 |

### 强制停止与恢复

“研究概览”中的“强制停止研究”由任务所有者或管理员操作；共享只读成员不能停止任务。网页先显示“正在强制停止”，确认进程退出并完成日志收尾后才显示“已强制停止”。请求超时或退出未确认时，页面不会宣称停止成功。

强制停止核对 Linux 进程身份，使用内核进程句柄终止目标主进程及计算子进程，防止 PID 复用导致误杀。该功能面向支持 pidfd 的 Ubuntu／Linux；已保存身份的原研究进程在网页服务重启后仍可停止。

已发送的 API 请求可能仍产生费用。停止不会自动生成新总结，也不会使未通过节点变为已验收。

有有效检查点时，可点击“恢复中断研究”；最后一个安全检查点之后的工作可能需要重做。没有可恢复检查点，或原检查点已完成时，可在任务结束后追加条件进行增量续研。尚有原进程或工作锁时，系统阻止重复恢复。

### 完整继承的范围

下一轮续研保留原问题、累计条件、锁定参数，以及旧代码、数据、图表、报告、节点输出、评分、评审和失败记录的研究快照。多代成果按来源任务组织，模型通过继承索引按需读取或复制复用。

完整继承表示资料被保存且可以访问；所有文件不会同时全文注入模型上下文。增量续研建立新的任务与研究树；断点恢复则尝试恢复原任务保存的执行状态。项目外依赖、外部数据服务和私人 API 密钥不作为研究成果复制。

历史验收只对应历史条件。新条件影响到的结果必须重新核对；复制文件或引用旧评分不能自动完成本轮验收。可在“成果交付 → 继承与复用”查看来源、文件和使用记录。

## 评分、验收与修复

**科学分**反映 Critic 对当前科学或方法内容的评估；**综合 reward**用于研究树排序，结合适用的执行、交付、参数证据与表达维度。科学通过／重做阈值作用于科学分，分数均不代表统计置信度。

科学分高于通过阈值，仍可能因关键问题未解决、评审字段缺失、文件未核实、参数违规或执行证据不足而不能验收。旧节点应按其保存的阈值与评审记录判断，不能套用当前输入框的新值。

Critic 原始建议与程序规则后的最终决定分别记录。网页展示不一致的原因和核对依据；修复或重评受次数预算限制，用尽后保留部分完成或失败状态。

reward 为 0 时，应展开节点区分：有效科学零分、无效／缺失评分、执行失败、交付缺失和内部未评分占位。文件存在、执行成功与科学正确性分别核对，降低阈值不能替代补足证据。

## 工具、来源与预算

### 能力开关

| 能力 | 用途与准备 |
| --- | --- |
| WebSearch | 通过配置的搜索服务检索网页；Tavily 需要个人搜索密钥与 SDK |
| 来源正文读取 | 读取公开 HTTPS 来源正文；需要同时启用 WebSearch，正文提取可能不完整 |
| arXiv | 独立论文检索，关闭 WebSearch 不会一并关闭它 |
| CODATA | 查询本地物理常数表 |
| Python | 执行模型生成代码；所需数值库必须已安装 |
| Skills | 加载已有技能说明和技能文件 |
| Workflow | 匹配已有研究流程模板 |
| Prior | 检索预先准备的向量知识库，需要索引、嵌入模型与相关依赖 |

开关按任务保存，续研时可调整；勾选不会自动申请密钥、安装依赖或构建索引。Python 执行访问的是服务器环境，当前系统面向相互信任的小组成员，不提供不可信多租户代码隔离。

### 不允许搜索的网站

在“工具与用量”中，由管理员设置全组 WebSearch 来源排除列表，例如每行一个域名。匹配包括该域名与子域名。列表之外的公开 HTTPS 来源均可尝试检索与读取，但能否返回内容仍受提供商覆盖、网络和网页自身限制。

v9.6.2 起，旧 `config.yaml` 中的 `tools.allow_domains` 不再用于这条 WebSearch／正文读取路径。排除规则变化会影响缓存命中，旧缓存与证据记录保留。该设置不约束独立 arXiv 检索或 Python 自行发出的网络请求。

### 三类预算应分别查看

| 预算 | 网页位置与含义 |
| --- | --- |
| 模型请求／token／估算费用 | “运行配置”与“工具与用量”；根据已记录请求及服务返回的用量检查 |
| 网页搜索／正文读取次数 | “工具与用量”的联网次数预算；同一任务、同一条件版本由所有角色和候选共享 |
| 研究轮数／节点调用轮数 | 基础配置中的研究与求解预算；控制研究展开及单节点工作量 |

任务证据缓存命中不增加新的联网次数，达到次数上限时仍可读取有效的已有缓存。无结果、筛选未保留或提供商失败也可能已经消耗请求次数。调整联网上限保留已用计数，不自动重新执行失败的搜索。

“每百万 token 费率 JSON”用于费用估算，字段为 `input`、可选的 `cached_input` 和 `output`，按实际模型 ID 配置。费率不含密钥，不决定提供商账单；研究用量面板不包含独立的网页翻译请求。当前尚不自动识别 DeepSeek 峰谷时段或节假日。缺少费率或用量字段时，费用可能无法完整估算；费用／token 上限也不能保证中途取消已经发出的请求。

### 并行与快速探索

网页可设置并行工作进程数与探索候选数，提交到下一次新建／续研任务；运行中的进程池不会即时改变。系统当前同时执行一个研究任务，其他任务排队；同一任务内部可并行求解多个节点。

快速探索仅对符合条件的官方 DeepSeek `draft` 请求关闭 thinking，不自动更换模型，不作用于所有研究角色。关闭快速探索，也可以通过角色设置让初稿使用 Flash、修订使用 Pro。

初次运行可从 **2 个并行进程、2 个探索候选、快速探索关闭** 开始，再按任务计算量、云端内存、API 响应时间与费用调整。并行增多不保证耗时成比例下降，候选、修复和重评也会增加请求。

## `config.yaml` 与研究数据

**当前版本不能删除根目录 `config.yaml`。** 它仍提供研究流程、轮数、超时、修复策略、工具路径和网页初始值。小组网页模式的 API 地址、密钥和角色模型由个人设置覆盖；日常使用不需要把个人真实密钥重复写入 YAML。

| 文件或目录 | 作用 | 更新时 |
| --- | --- | --- |
| `config.yaml` | 系统基础配置与默认值 | 保留 |
| `team_data/` | 账号、加密 API 配置、主密钥、组内设置等 | 保留并完整备份 |
| `.cache/` | 本地缓存 | 保留 |
| `.venv/` | 云端 Python 环境 | 保留，不由补丁重建 |
| `outputs/` | 研究历史、成果和任务配置 | 保留 |
| 各任务的 `web_config.yaml` | 本次研究实际配置快照，供执行和恢复读取 | 保留 |

API 密钥加密保存，页面不回显原密钥。备份 `team_data/` 时需要包含 `master.key`；仅保留加密的成员文件不足以恢复 API 配置。部署、备份与版本控制应保留真实密钥及研究资料的私有性。

新研究目录采用北京时间的“日期 + 研究主题 + 第几轮研究 + 时间”命名，例如 `2026-10-06_弹簧振动_第01轮研究_210000`；同名时处理冲突。这里的研究轮次指新建／增量续研次数，与任务内部 MCTS 搜索轮数分开。旧目录保持原样。

| 任务目录内的资料 | 内容 |
| --- | --- |
| `query.txt`、`task.json`、`console.log` | 任务问题、历史元信息与控制台日志 |
| `web_config.yaml` | 任务配置快照 |
| `query/contract.json` | 研究契约 |
| `query/node_<编号>/` | 每个节点的代码、数据及相关成果 |
| `query/research_monitor/` | 轮次和节点监看记录 |
| `query/live_updates/`、`query/revisions/` | 条件队列、回执与版本记录 |
| `query/inherited/`、`query/inheritance.json` | 继承快照、来源及索引 |
| `query/research_checkpoint.json` | 安全检查点 |
| `query/summary.md`、`query/completion.json` | 本轮总结与完成核对记录 |
| `query/final/`、`query/final_manifest.json`、`query/delivery_index.md` | 发布成果、清单与索引 |

以上文件按实际执行阶段生成，并非每个失败或提前中断任务都会拥有全部文件。下载总结支持 Markdown、TXT 和 HTML；HTML 可由浏览器打印为 PDF。任务要求完整 PDF 报告时，仍需生成和核对单独的报告交付物。

## Ubuntu 安装与维护

### 已有部署

现有服务由 `physmaster.service` 管理，在项目虚拟环境中运行，并通过现有 Tailscale Serve 私网地址访问。网页服务器监听本机地址；无需为本项目开放公网端口。

```bash
sudo systemctl status physmaster.service
sudo journalctl -u physmaster.service -n 100 --no-pager
```

重启网页服务可能中断研究并使登录会话失效。优先等研究结束后维护；不要在已由 systemd 管理的同一端口另启第二个服务器。

### 首次准备完整源码

需要 Python 3.10+。v9.6.3 强制停止功能需要支持 pidfd 的 Ubuntu／Linux 与 Python 运行时；安装脚本会检查。Prior 等可选能力需额外准备。

取得对应版本的完整源码后，在项目根目录操作：

```bash
python3 -m venv .venv
source .venv/bin/activate
python -m pip install -r requirements-web.txt
python -m pip install cryptography tavily-python
```

已有环境无需重建。首次缺少 `config.yaml` 时复制示例，已有配置保留：

```bash
if [ ! -f config.yaml ]; then
  cp config.example.yaml config.yaml
fi
```

管理员在服务停止时创建最多三名成员，密码通过终端交互输入：

```bash
python team_admin.py add-user admin --admin
python team_admin.py add-user member1
python team_admin.py add-user member2
```

已经存在的账号不要重复创建。忘记密码时，管理员停止服务后使用 `python team_admin.py reset-password 用户名`，再启动服务。

手动确认小组服务能运行时：

```bash
python web_server.py --team --cfg_file config.yaml \
  --host 127.0.0.1 --port 8765 \
  --public-url https://你的实际Tailscale-Serve域名
```

将示例 URL 替换为浏览器实际访问的根地址。它用于 Host／Origin 校验，本身不会申请域名或配置 Tailscale。私网接入和 systemd 服务由部署管理员设置；已有部署保留原地址与服务配置。

### 云端补丁规范

后续补丁默认适配：

- 项目：`/home/ubuntu/physmaster/PhysMaster-v9`
- 服务：`physmaster.service`
- 访问：现有 Tailscale Serve 私网 HTTPS
- 数据保护：不覆盖 `team_data/`、`.cache/`、`config.yaml`、`.venv/`、`outputs/`、`.env`、`.git/`

将补丁解压到项目目录之外，在补丁目录执行：

```bash
sudo bash update_physmaster.sh
```

脚本按补丁范围进行兼容性与依赖检查，备份原程序文件，应用更新并检查服务健康；失败时自动回滚。需要重启的补丁会拒绝在活动研究期间安装。更新期间小组成员不要提交新任务。

补丁是增量更新，不能单独运行。v9.6.3 需要已安装 v9.6.2；更早的工作台与云端能力按相应补丁说明补齐。热更新与重启要求以具体补丁 README 为准。代码备份用于回退程序，不替代对研究数据和账号的完整备份。

## 常见问题

| 现象 | 建议检查 |
| --- | --- |
| 页面刷新超时或 `fetch fail` | 查看失败接口、服务日志和私网连接；页面保留旧记录不代表后台已停止 |
| 发送条件后没有变化 | 核对排队／生效回执；当前模型请求或计算尚未到达轮间检查点 |
| 研究卡住，暂停无效 | 使用 v9.6.3 强制停止，并等待确认退出；有安全检查点再恢复 |
| 停止请求超时 | 先读取任务状态，避免将超时当作停止成功或盲目重复提交 |
| 恢复按钮不可用 | 检查原进程／工作锁、检查点完整性与原任务是否已经结束 |
| 共享任务无法修改 | 共享默认只读；修改、停止和续研等写操作由所有者或管理员执行 |
| WebSearch 没有被调用 | 检查任务能力、个人 Tavily 密钥、SDK、联网预算与节点实际研究需求 |
| 联网预算用尽 | 看当前条件版本的已用／上限；调整上限保留已用计数，与模型账户余额分开 |
| 科学分达标仍未验收 | 展开关键问题、程序证据和最终规则决定；分数只是验收条件之一 |
| 文件存在却未核实 | 核对声明路径、节点归属、内容、哈希和实际交付清单 |
| 中文翻译失败 | 确认个人 API 地址与密钥可用且支持 deepseek-flash；保留原文排查 |
| 新页面没有显示 | 刷新浏览器，确认正在访问正确部署；必要时强制刷新检查缓存 |

## 测试与当前边界

最近的 v9.6.3 补丁通过 **9 个 Python 测试方法与 4 组 jsdom 交互检查**，覆盖 Flash 翻译配置与缓存、真实测试进程树停止、重启后的进程身份、权限校验、状态显示、文件保护、安装及健康失败回滚。Python／JavaScript／Shell 语法与补丁文件校验通过。

真实进程测试执行了 pidfd、SIGSTOP 和 SIGKILL；本地测试环境的 PID／proc 视图对齐由测试专用适配完成，适配不会安装进生产项目。systemd 更新通过测试替身验证，翻译采用离线传输替身。

该记录对应新增功能，没有重复测试全部历史科研功能，没有调用真实付费 API，也未在用户腾讯云机器完成部署实测或真实浏览器视觉验收。各补丁的详细范围以随包 `TEST_REPORT.md` 为准。

当前需要人工关注的边界包括：模型可能提出不充分的假设、漏读继承资料、产生错误代码或结论；外部检索不保证完整；文件与代码绑定核对不证明全部物理语义；预算不保证准确预测费用；断点只覆盖已保存的安全状态。建模比赛成果应由组员复现主要数值并核对论文与代码的一致性。
